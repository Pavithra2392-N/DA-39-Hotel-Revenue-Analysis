# DA-39 Hotel Revenue & Occupancy (RevPAR) - Project Kit
1. Read docs/00_START_HERE.md (step-by-step, day-by-day).
2. pip install -r requirements.txt
3. Put the Kaggle CSV in data/raw/hotel_reservations.csv
4. Run, from this folder:
   python scripts/01_clean_data.py
   python scripts/02_build_tables.py
   jupyter notebook scripts/03_eda_notebook.ipynb
5. SQL: sql/01_schema.sql + sql/02_queries.sql (SQLite file data/hotel.db is created for practice)
6. Dashboard: docs/01_dashboard_guide.md
