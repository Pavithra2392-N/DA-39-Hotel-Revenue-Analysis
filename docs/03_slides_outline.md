# Presentation Outline - 5 minutes, 7 slides (PowerPoint / Google Slides)
Aim: about 40 seconds per slide. Big numbers and charts, few words.

1. **Title + problem (30 s):** "Where does a hotel earn and lose revenue?" Name, project ID, the one business question.
2. **Data and cleaning (40 s):** Source, [N] rows, before/after table (3-4 key fixes), the capacity assumption.
3. **KPI headline (40 s):** 4 big cards - RevPAR, ADR, Occupancy, Cancellation %. One line explaining RevPAR = ADR x Occupancy.
4. **Insight 1 - Season and price (50 s):** monthly RevPAR chart, circle the peak and the low.
5. **Insight 2 - Channels and cancellations (50 s):** segment revenue vs cancel rate, lead-time chart.
6. **Dashboard demo (50 s):** screenshot (or live: click one slicer).
7. **Recommendations + limitations (60 s):** 3 actions with expected impact; 1 line on limitations.

Tips: do not read slides - tell the story: problem -> finding -> action. Keep the Python notebook, SQL file and dashboard open for the viva.
